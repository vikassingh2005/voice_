## 2024-05-24 - Missing ARIA Labels on Buttons
**Learning:** Icon-only buttons often lack accessible names for screen readers.
**Action:** Always verify icon-only buttons have an aria-label attribute.
## 2024-05-24 - Missing ARIA Labels on Theme Swatches and Icon Buttons
**Learning:** Icon-only buttons and UI elements like theme color swatches lack accessible names for screen readers even if they have visual titles.
**Action:** Ensure `aria-label` attributes are consistently applied to icon-only buttons and visual-only controls like color pickers.
